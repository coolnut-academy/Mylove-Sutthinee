งานธุรการในชั้นเรียน

เลือกงานที่ต้องการดูข้อมูลหรือจัดการเอกสารประจำชั้นเรียน

👥

สมาชิกในห้องเรียน

รายชื่อ เลขประจำตัว และข้อมูลประจำชั้น ป.1

→
📅

เช็กชื่อมาเรียน

บันทึกสถิติและการเข้าแถวมาเรียนประจำวัน

→
🪥

เช็กชื่อแปรงฟัน

กิจวัตรการแปรงฟันหลังอาหารกลางวัน

→
🥛

เช็กชื่อดื่มนม

การดื่มนมโรงเรียนเสริมสร้างสุขภาพผู้เรียน

→
⚖️

น้ำหนัก / ส่วนสูง

การเจริญเติบโตทางร่างกายและดัชนีมวลกาย BMI

→
🩺

บันทึกการตรวจสุขภาพ

การตรวจสุขภาพร่างกาย สุขอนามัย และช่องปาก

→
📝

แบบประเมิน SDQ

การคัดกรองพฤติกรรมผู้เรียนและระบบดูแลช่วยเหลือ

→
📁

บันทึก ปพ.

สมุด ปพ.5 (ผลการเรียน) และ ปพ.6 (รายงานประจำตัว)

→
🎮

ทะเบียนสื่อ / แหล่งเรียนรู้

คลังสื่อการสอน สื่อนวัตกรรม และเกมการศึกษา (รองรับลิงก์ภายนอก)

→
💬

บันทึก PLC

ชุมชนแห่งการเรียนรู้ทางวิชาชีพและแลกเปลี่ยนประสบการณ์

→
🔬

วิจัยในชั้นเรียน

วิจัยพัฒนาทักษะการอ่านสะกดคำภาษาไทย (STAD)

→
📖

แผนการสอน

แผนการจัดการเรียนรู้บูรณาการ Active Learning

→
🏆

ผลงานครู / เกียรติบัตร

เกียรติบัตรการอบรม รางวัลครูดีเด่น และผลงานวิชาชีพ

→
📘

รายงาน SAR

รายงานประเมินตนเองของสถานศึกษาและครูผู้สอนรายบุคคล

→
📎

เอกสารอื่น ๆ

เอกสารการเลื่อนขั้นเงินเดือน และแบบฟอร์มประจำชั้น
